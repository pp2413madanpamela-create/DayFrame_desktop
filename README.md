Scopul aplicației:
Aplicația “DayFrame” permite utilizatorului să-și organizeze eficient ziua prin jurnal personal, listă de sarcini, notițe și calendar. Cu ajutorul aplicației, la finalul fiecărei zile utilizatorul își poate forma o concluzie automată a activităților realizate, astfel sprijinind reflecția și productivitatea zilnică.
